# V1.3.43 · 任务分组、素材独立及预览图优先

- 界面改为「任务 → 广告计划」：每个任务内可以添加多条广告名称与展现形式，行末有删除小图标；任务下方可新增任务。新增广告行复制上一行名称与展现形式，但整批名称必须唯一。
- 每个任务独立设置计划类型、场景定制、创意类型（与任务内所有展现形式兼容）、创意规格、媒体和预览图。同任务多条计划复用这一组文件句柄，不复制素材字节；不同任务互不混用素材。
- 图片/视频与预览图的选择框在同一行，均只显示已选数量。视频预览图支持按视频逐张指定和批量顺序指定；用户指定优先，普通视频没有指定时沿用原第三帧抽取和平台兜底；「激励互动＋竖版视频」没有指定时保持跳过，选了则逐条上传。
- 创意规格默认 `1080*1920`，另可选 `1080*1880`；平台没有「创意规格」字段时直接忽略。广告名称实时辅助识别六种展现形式，用户手动选择优先。
- 原广告组改为底部「公共参数设计」，新增公共应用名称/标题、副标题；安装定向仍默认「已安装」。移除「执行与投放安全」区，所有新批次默认自动最终提交。
- 新任务在后台展开为稳定的计划序列，进度展示当前任务和任务内计划；PLAN、AD 分别读取所属任务配置，GROUP 读取公共参数。保留旧版本进行中的扁平任务读取兼容逻辑、错误自动暂停、继续任务、主动停止、新批次替换、成功返回广告计划并刷新。
- 整批最多十条实际广告计划、每任务最多十个素材；提交前检查唯一名称、展现形式/创意类型兼容、素材数量与视频预览图对应关系。

验证：JavaScript 语法检查、任务嵌套 UI 模拟、后台状态与校验模拟、文件句柄分组模拟及视频预览图优先逻辑模拟。真实 vivo 平台的提交与上传仍需先做小批量验证。
