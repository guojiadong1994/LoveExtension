# V1.3.38 · 关闭批量任务提示窗口即主动停止

- 右下角批量任务进度窗右上角「×」：运行中、暂停或出错待人工处理时，发送 `STOP`，收到后台确认才真正关闭窗口。
- 关闭后任务状态为不可恢复的 `stopped`，点击「继续任务」会被后台拒绝；已完成的广告不会撤销，停止时不关闭工作页面。
- 后台 `STOP` 增加任务 ID 核验，防止页面切换时误停止新任务；日志记录「点击进度窗 ×」原因。
- 发送停止失败时不隐藏窗口，而是保留错误；按钮防重复点击。
- 已完成或已停止的任务只关闭提示，不会调用多余的停止操作。
- 原有「停止任务」按钮、暂停后继续机制、自动返回刷新和素材逻辑不变。原旧版悬浮球、改名和上传文件字节不变。
- 根目录及批量创建两份使用说明已经同步到 V1.3.38。
