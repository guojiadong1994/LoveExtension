# V1.3.30：每条广告独立选择展现形式

- 将原批量新建「广告创意」区的公共「展现形式」移到每个「广告名称」右侧，形成一行一套广告的关系。
- 新增广告名称时，继续复制上一行名称，同时复制上一行展现形式。删除行时名称与展现形式一起删除，序号更新。最多10套。
- 任务数据新增 `config.displays`（与 `config.names` 一一对应），后台验证长度和取值，每次执行广告创意时读取 `displays[index]`；旧会话里的 `config.display` 仍支持。
- 平台各展现形式的创意类型选项依据用户提供的截图验证；下面的「创意类型」「创意规格」「素材」仍为公共配置。不支持的类型组合在开始之前阻止，避免创建计划后失败。
- 共用创意规格只在该展现形式对应页面实际提供「创意规格」字段时设置。
- 旧的 `content.js`、`style.css`、`workflow/`、联动目录与浏览器级点击模块均未修改。
- 未对 vivo 网站进行真实创建/投放测试。
