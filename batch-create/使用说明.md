# LoveExtension V1.3.48 · 批量创建使用说明

本版本保留原有广告改名、一键素材上传、一键检测功能；左下角悬浮球已由广告页右键快捷菜单替代。批量创建继续从广告计划列表的空白处右键进入。

**V1.3.44 补充**：纯图片任务没有预览图时，图片对应的空预览图占位不再被误认为非法。任务内部「＋ 添加广告计划」改为整行虚线选择框，背景透明，保持任务卡片原有颜色。

**V1.3.45 补充**：「公共参数设计」新增「曝光监测地址」「点击监测地址」「DeepLink」。三项可全部留空，沿用平台原有字段内容；一旦填写其中一项，就必须填写完整三项。仅点击「开始批量创建」时调用原「检查地址/一键检测」的四项基础链接校验，**不读取、存储或逐字符串对比旧链接**。校验不通过会在开始按钮同行显示错误，批次不会启动。通过后每条广告在 AD 阶段自动填写这三项并核对值，校验不通过或填写失败时暂停、允许人工修复并继续。

**V1.3.46 补充**：在 vivo 广告**新建或编辑页面**的空白处点击鼠标右键，显示「一键素材+文案」「一键检测」两个选项；左键选择后使用原有弹窗与处理逻辑。输入框、按钮、链接等交互区域继续使用浏览器原生菜单。快捷菜单可通过单击外部区域或按 ESC 关闭。广告计划列表中的「批量新建广告」右键入口不变。

**V1.3.47 补充**：「一键素材+文案」弹框内的「预览图」不再只支持激励互动竖版视频。已有创意可以**只选择预览图**并直接替换现有的对应图片（要求平台当前创意确实有「预览图/封面」独立上传字段）；也可与主素材、标题一同处理。普通视频选了预览图就优先使用，未选部分继续自动抽帧；激励互动竖版视频继续不自动抽帧，允许只选部分预览图。所有已选择图片按创意顺序逐一对应，最多10张，不复用文件。

**V1.3.48 补充（两个入口不同）**：「批量新建广告」中任务卡片右侧的「预览图（可选）」改为**直接选择 JPG/PNG 图片**，与左侧素材框一样，只显示选择数量，不再弹出「逐视频设置」窗口。这里选的图片**只会用于「激励互动＋竖版视频」**，其他视频继续按原流程自动抽帧；不选则跳过，不要求每个视频都选图。该入口需先选择视频，最多选与视频数量相同的预览图。**广告编辑页右键「一键素材+文案」保持 V1.3.47 的独立预览图功能原样不变。**

## 一、配置结构

- **整批任务**：可包含多个独立任务，最多创建 **10 套完整广告**（以全部任务内广告计划行数之和计算）。
- **任务**：每个任务可新增多条「广告名称＋展现形式」，这些计划共用当前任务的计划类型、场景定制、创意类型、创意规格、图片/视频素材和预览图。不同任务素材独立。
- **公共参数设计**：位于所有任务下方，整批共用推广应用、一级行业与二级产品、安装定向、出价方式、优化目标、出价金额、应用名称/标题、应用副标题，以及三项监测链接。
- **自动提交**：新批次默认在填写完成后自动点击最终「提交」，取消原「执行与投放安全」勾选区。提交可能让真实广告进入投放并产生费用，请先小批量确认配置。

## 二、添加与删除

1. 在任务内点击「＋ 添加广告计划」，新增一条「广告名称／展现形式」，自动复制该任务上一行的名称及展现形式，方便改名。行末的小垃圾桶删除对应行；每个任务最少保留一行。
2. 点击「＋ 新增任务」增加独立素材组。新任务继承上一任务的普通计划参数及最后一条广告名称/展现形式，素材和预览图留空；点击任务头部的小垃圾桶删除整个任务。
3. **所有广告名称必须唯一**；添加时复制的名称需要修改。输入名称包含「开屏、Banner、插屏、原生、激励互动、信息流」之一时，自动辅助选择展现形式；手动切换后不再强制覆盖。
4. 同一个任务内可选不同展现形式，但必须都支持当前任务的公共创意类型。不兼容会在开始前指出哪条计划有问题。
5. 创意规格默认 **1080×1920**，也可选 1080×1880；平台没有创意规格字段时自动跳过。安装定向默认「已安装」。

## 三、图片、视频及预览图

- 每个任务只选择一次图片或视频素材（最多 10 个），任务下所有广告计划都会使用该组素材；不同任务互不混用。
- 媒体类型由创意类型自动识别，无图无需素材；变更为不兼容的类型会清除当前任务已选素材。
- 素材与预览图选择框各占一半宽度，只显示选择数量，不列出文件名。
- 批量创建的「预览图（可选）」只对含「激励互动＋竖版视频」计划的任务开放；先选择视频，再直接选择 JPG/PNG 预览图，不打开逐视频编辑窗口。已选择图片依次对应前面的创意，图片数量不能超过视频数。
- **普通视频**：批量任务的预览图选择框不参与普通视频处理，仍按原本的第三帧提取、平台自动生成兜底。
- **激励互动＋竖版视频**：预览图由用户可选地提供，选中的图片逐条替换，未选的跳过，不做自动抽帧。
- 本地只存 **File System Access 文件句柄和小段文件元数据**，不会复制图片或视频字节到数据库；请勿在运行中移动或修改原文件。

## 四、执行与异常恢复

**监测链接检测时机**：在配置窗口粘贴链接期间不会自动检测；点击「开始批量创建」后，先执行原「检查地址」的四项基础规则（partnerId、链接类型及结构、vivo 渠道一致性、ugParams.taskId 一致性）。检测失败会留在配置窗口，不会上传素材或新建广告；检测成功才开始逐条创建。历史链接的严格逐字比对完全不参与该流程。三项留空则不检测、不回填。

**广告页面填写**：每条广告进入 AD 页面后，用表单标签查找曝光、点击、DeepLink 三个真实输入框，填写并读取核对后才进入自动提交。如果页面字段加载失败或不可编辑，将自动暂停，允许人工调整后继续任务。

整批按照任务及任务内广告计划的顺序执行。每条都单独完成：

PLAN（广告计划）→ GROUP（广告组）→ AD（广告创意）→ VERIFY（广告列表核验）

只有通过核验才计入已完成。右下角显示总进度，以及当前任务号、任务内计划号和阶段。

任意环节发生平台报错、加载失败、素材上传失败、最终提交错误等，都会进入暂停并直接显示「继续任务」。你可以在工作标签页人工修好，再点击继续；不需要「人工接管」按钮。AD 页面人工修复后不会自动重复上传已经处理过的素材。

若此前已经点击「保存并继续」或「提交」但结果不明，点击继续前请核对平台是否已经创建，避免重复广告；再次点击继续只允许重新检查并尝试一次提交。**主动点击「停止任务」或右下角窗口的 × 都会永久停止，并隐藏状态框**。

在广告列表 VERIFY 阶段如暂停，需要你实际确认广告已经创建，才能点击「人工确认已创建，继续」。

## 五、完成、新任务与安装

- 全部成功后，返回原广告计划列表、刷新并关闭扩展打开的工作标签页；成功提示约 1 秒自动消失。
- 右键打开新配置窗口不会打断旧批次。只有新批次通过校验并真正点击「开始批量创建」，旧批次才被替换；旧批次的上传句柄引用会清理，不会删除电脑上的文件。
- 在 Chrome 扩展管理页面（chrome://extensions/）打开开发者模式，解压 ZIP 后加载 LoveExtension 文件夹。升级旧版请更新目录、重新加载扩展并刷新 vivo 页面。不要同时启用多个版本。
- 推广应用和「一级行业 → 二级产品」可通过「管理应用、行业与产品」维护多条关联、默认项以及 JSON 导入导出。
- 行业/产品与优化目标的浏览器级点击仍会使用 Chrome debugger。运行中不建议占用当前标签的 F12 调试连接。

## 六、验证范围

已完成源码语法检查、UI 行为模拟、任务映射与自动提交校验模拟、分组句柄与视频预览图映射模拟、视频自动抽帧/用户封面优先模拟。

尚未在你的 vivo 实际账号上跑完整投放链路，建议先试 **1 个任务、2 条广告计划**，确认素材、提交及列表结果后再扩大批量。
