# LoveExtension V1.3.46 · 广告页面右键快捷菜单

## 改动

- 广告新建、编辑页面（`/marketing/ads/add/...`、`/marketing/ads/edit/...`）在**空白区域右键**弹出快捷列表：
  1. 一键素材+文案
  2. 一键检测
- 左键选中后分别调用原 `openCombinedCreativeDialog()` 和 `runLoveLinkCheck()`，不修改上传、校验与历史链接比对逻辑。
- 删除左下角悬浮球和不再使用的拖拽/悬浮样式，保留原有 Toast 通知初始化、运行守卫与 ESC 停止功能。
- 在输入框、按钮、链接、图片、弹窗和可编辑区域右键继续使用原生浏览器菜单；选中文字后也保留复制菜单。
- 右键菜单在点击外部、ESC、页面滚动或调整窗口尺寸后关闭；自动限制在可视区域内。
- 广告计划列表的右键「批量新建广告」保持不变，其他网站页面不显示上述菜单。

## 验证

- 自动化模拟测试涵盖：路径限制、交互区域、文字选择、视口边界、两项按钮调用原有功能、关闭行为以及悬浮球移除。
- 既有批量创建、素材映射、续跑与链接检测测试继续通过。
- 尚未在用户已登录的 vivo 广告后台进行完整人工 UI 验证。
