# LoveExtension V1.3.25 — 推广应用与行业/产品两级联动

## 关联管理

在广告计划空白处右键打开「批量新建广告」，点击「管理应用、行业与产品」：

- **推广应用**：平台显示的完整名称。
- **一级行业（左侧菜单）**：例如 `金融-第三方支付`。
- **二级产品（右侧菜单）**：例如 `支付宝-便捷生活一点就好`。
- 同一个应用可设置多条行业/产品关联；可指定一条为默认关联。一个应用只有一条完整关联时，创建配置中自动选中。
- 支持编辑、删除、设置/取消默认，JSON 导入/导出。只存储文字信息。

旧版 `loveBatchV1:applicationCatalog` 数据**保留在原有存储键下**，可以明确按单个 `→` 拆分成两级的旧关联会被读取为新的一级行业与二级产品；缺少 `→` 或包含多个 `→` 的旧关联会作为「待完善旧关联」显示，必须人工编辑为两个明确的层级后才能用于创建。首次保存/管理后写为 v2 格式。不会清空旧记录，也不会自动猜测不明确的层级。

## 自动执行

在 GROUP 步骤，选择推广应用后，通过已获得授权的 `chrome.debugger` 浏览器级鼠标操作：

1. 精准定位「行业/产品」字段并展开下拉层。
2. 查找 **唯一** 的一级行业选项，点击左侧行业。
3. 等待右侧产品菜单出现，查找 **唯一** 的二级产品选项并点击。
4. 必须在表单字段的选中回显里同时验证行业与产品，才能继续填写定向与出价。

任一步骤找不到/多选/被遮挡/没有选中回显，立即停止，不自动保存广告组。操作完成或出错后断开 debugger。不会操作其他标签页。

## 安全和测试范围

- 这版基于 V1.3.24，原有 `content.js`、`style.css`、`workflow/` 保持字节不变。
- 真实 vivo 网站的级联菜单 DOM 尚未提供 Inspector 数据，浏览器模拟的结构不等同于真实账户，因而**真实页面自动选择是否成功仍需验证**。
- 安装前可备份旧 JSON；更新前不要卸载旧扩展，以免本地数据丢失。
- 试运行前请核对计划是否已保存，使用新的广告名称避免重复创建。建议首次不启用「自动提交」。
