# V1.3.44 · 图片任务预览图校验与按钮布局修复

1. 修复 V1.3.43「任务N的预览图对应关系无效」：非视频素材组也会保留与文件数量相同的空预览图位置。此前误用数组长度判断「有预览图」，导致纯图片任务被拒绝；现在只判断是否实际提供了非空预览图句柄。10 张图片＋10 个空占位可以正常存储，图片任务若错误混入真实预览图仍会拒绝。
2. 「＋ 添加广告计划」与「＋ 新增任务」使用相同的整行虚线框布局；前者背景透明，沿用任务卡片底色，不显示蓝色填充。
3. 其他批量创建、自动提交、按任务共用素材、暂停继续和返回广告计划页面的逻辑不变。

验证：语法检查、界面模拟、10 张纯图片零预览图与非法图片预览图回归、后台状态校验和视频预览图优先逻辑模拟通过。真实 vivo 平台仍需小批量实际验证。
