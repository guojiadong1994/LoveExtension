# LoveExtension V1.3.18 — 联动列表与错误弹窗

本版仅修改 `batch-create/` 目录及扩展清单的版本号和新脚本注册。旧版 `content.js`、`style.css`、`workflow/` 不变。

## 推广应用／行业产品关联

- 批量新建弹窗使用二级下拉选择：先选推广应用，再选本应用关联的行业/产品。
- 点击「管理应用与行业/产品」，可以添加、编辑、删除应用与行业/产品的关联；同一个推广应用可以保存多个行业/产品。
- 关联保存在 `chrome.storage.local` 的 `loveBatchV1:applicationCatalog`，仅保留名称文字，不保存图片、视频文件内容。
- 提供 JSON 导入和导出。导入时会覆盖当前列表。更新扩展时，Chrome 正常保留已有的本地存储；彻底卸载后可能丢失，请提前导出备份。
- 行业/产品若为两级路径，例如「金融-第三方支付 → 支付宝-便捷生活一点就好」，请用 `→` 分隔层级；名称内的连字符 `-` 保留原意，不当作路径分隔符。
- 广告组自动化仍会在 vivo 页面依次选择应用、行业/产品。任何一步无法确认唯一选中都会停止，避免误操作。

## 右下角任务提示

- 新增「× 关闭提示」，关闭后不会被同一任务状态的定时轮询重新打开；任务状态变化（运行中转为失败等）时会重新提醒。
- 失败时显示「复制错误」，复制内容包含版本、页面、任务编号、任务名称、阶段、详细错误和最近执行记录；复制成功后按钮显示「已复制」。
- 关闭提示不会继续任务、重试任务或者删除已经创建的广告。

## 验证建议

建议使用测试账户，先维护一个应用与行业/产品关联，再开始仅一套的测试任务。**真正创建与提交广告可能产生费用**，请保留最终手动确认。
