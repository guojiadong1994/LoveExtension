# V1.3.23 优化目标菜单事件修复

## 用户实测依据

- 代码点击 `div.ep-select.form-control`：只有 `click`，`isTrusted=false`，菜单无选项。
- 鼠标手动点击 `input.ep-input__inner`：产生 `pointerdown` / `mousedown` / `mouseup` / `click`，菜单中的 `自定义付费` 可见且未禁用。

## 修改

- 仅调整 `batch-create/content.js` 的 `chooseDropdown()` 及相关辅助逻辑。
- 优先定位 `优化目标` 内层 input，模拟鼠标的 `pointerdown`、`mousedown`、`pointerup`、`mouseup`、`click`（合成事件），每个关键阶段检测菜单是否已经显示。菜单显示即停，防止后续点击关闭菜单。
- 限定 `.ads-app__cvtype-select` 弹层中的可见、非禁用选项，精确匹配后检查控件回显。
- 不采用平台内部接口，不提升扩展权限，不自动重试广告保存和提交。

## 限制

合成事件的 `isTrusted` 仍为 false。若 vivo 平台显式限制非真实事件，这一修复无法强制展开菜单，需要进一步根据实际运行结果改用人工辅助或浏览器级授权交互。测试限于本地浏览器模拟，尚未在真实 vivo 平台验证。
