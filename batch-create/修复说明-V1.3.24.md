# LoveExtension V1.3.24 — Chrome 浏览器级点击「优化目标」

## 本次变更

- 新增 `batch-create/debugger-input.js`，只服务于「批量新建广告 → 广告组 → 优化目标」下拉框。
- 后台先验证：发送请求的页面为当前任务绑定的工作标签页，任务处于 GROUP/busy，所选目标与任务配置一致。
- 使用 Chrome `debugger` 权限连接绑定的 vivo 新建广告标签页；按 live DOM 获取输入框和选项位置，通过 `Input.dispatchMouseEvent` 发送鼠标移动、按下、抬起操作；逐次确认下拉菜单展开和优化目标已选中。任何异常均停止该步，不自动继续保存。
- 每次操作后在 `finally` 中断开 Chrome 调试连接，不持续监控或调试其他网站。
- 原有悬浮球、上传/文件句柄、右键已有计划的工作流、批量创建其他字段不改动。

## 安装注意

Chrome 会显示 `debugger` 调试权限警告，操作过程中可能显示调试提示条，这是浏览器的正常行为。

如在使用 F12 开发者工具检查同一个新建广告标签页，请先关闭 DevTools 再启动批量创建，否则 Chrome 可能拒绝同时附加调试会话。不要在任务执行中刷新、关闭工作页或重新加载扩展。

## 安全和验证

- 此能力只在当前被绑定的 `https://ad.vivo.com.cn/marketing/ads/add/` 工作标签页、GROUP 阶段使用。
- 不能选中或校验失败时会停止批量任务，不绕过 vivo 平台校验，也不会重复点击保存/提交。
- 本地模拟浏览器验证了 CDP 点击能触发 `isTrusted=true` 的输入事件，且“自定义付费”可被选中；真实 vivo 页面仍需用户安装验证。
- 如果 GROUP 阶段失败，PLAN 阶段可能已保存，重新测试请换新名称并检查原记录，防止同名计划重复创建。
