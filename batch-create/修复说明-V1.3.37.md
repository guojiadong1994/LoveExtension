# V1.3.37 · 任务异常暂停、人工接管、断点继续

- 自动失败由不可恢复的 `failed` 改为 `paused`，保留 `stage`、`phase` 检查点、当前标签页、已完成结果、原素材句柄和日志。
- 每个阶段支持人工修复并继续；新增状态窗口按钮「人工接管」「继续任务」「停止任务」。仅明确手动停止进入不可恢复的 `stopped`。
- `RESUME` 校验任务绑定标签页和当前页面阶段；允许同阶段恢复、人工已完成进入下一阶段、或在已发出 SAVE/SUBMIT 的检查点核验进入下一阶段。
- 禁止自动重复触发已有提交检查点，尤其广告的最终提交。手动修复 AD 后不重复批量上传。
- GROUP 应用已正确选择时不重新展开；行业/产品只对明确的瞬时布局异常做一次有界重试，仍不确定则暂停。
- 修复原先所有非 running 状态都清除素材句柄的问题；仅完成或用户停止后清理。
- 根目录与 batch-create 说明同步更新为 V1.3.37。
- 旧版 `content.js`、`style.css` 和 `workflow/` 仍保持文件字节不变。
- 人工修复过的 GROUP 字段按本套保留跳过记录：先修好行业产品、随后修好优化目标的两次暂停不会互相丢失；阶段切换时清理这些跳过标记。
- VERIFY 可在用户明确点击「人工确认已创建，继续」后以 `manually-verified` 记录人工核验。注意必须真实核对广告确已创建；不会自动推断。
- 初次打开工作标签页失败也会暂停，并允许在来源计划页点击继续重新打开；未持久化的任务才会回收原始素材句柄。

- 提交前确认弹窗的取消选项改成「暂不提交，人工接管」，执行暂停 `PAUSE` 而非不可恢复的 `STOP`；只保留进度窗「停止任务」作为永久停止入口。

- 媒体上传的各独立阶段之间新增任务状态检查，人工接管后不会自动启动下一轮预览图或文案填写（已经发起的单次平台上传不承诺能中断，须等当前操作结束后核对）。
