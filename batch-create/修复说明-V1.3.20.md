# LoveExtension V1.3.20 修复说明

## 修复内容
- 修复广告组阶段选择「优化目标」时，平台已经显示目标选项但扩展仍超时的问题。
- 识别 `.ep-select-dropdown__item` 内层 `.cvtype-info` 真实文字，支持层级不同的标准下拉选项。
- 优先使用当前选择框的关联下拉列表，遇到多个可见弹层时使用与该字段的距离识别；不能唯一确定则停止。
- 点击后检查选择框回显，不能证实选中时停止，防止误操作。
