# LoveExtension V1.3.29 完成提示自动隐藏

- 批量新建广告的任务状态为 `completed` 时，右下角“全部完成”提示在显示 **5 秒** 后自动关闭，不再一直占用页面。
- 自动关闭后，轮询不会再次把同一任务的成功提示弹出来。
- 轮询刷新进度不会重置倒计时；新任务或状态变化时会取消旧计时器，避免误关闭正在运行或失败的提示。
- `failed`/`stopped` 状态不自动关闭，保留人工排查、复制错误和手动关闭能力。
- 仅修改 `batch-create/content.js`，更新 `manifest.json` 版本和本说明；悬浮球、右键改名、素材上传、批量自动化流程没有变化。
