# V1.3.39 · 出错直接暂停，继续任务自动接续保存/提交

- 自动化 `FAIL` 统一进入 `paused`；右下角立即显示「继续任务」，无需先点「人工接管」。
- 保存/提交超时后，若恢复时仍在相同表单阶段，不再要求人工按平台的保存按钮。用户点击「继续任务」即授权**一次**恢复尝试；先确认是否已到下个页面，再校验本页目标名称、未处理的系统弹窗及保存/提交按钮，最后仅对当前阶段发送一次点击。
- 增加提交前 `MARK_TRANSITION_DISPATCH` 检查点，用于区分已准备和即将发送的点击；中断恢复不会通过计时器自动无限重试。
- 若平台已进入下一阶段则直接沿用，不重复点击；人工修好的表单/素材不重新填写和上传。
- 已到 VERIFY 后保留广告列表核验；点击右上角「×」仍永久停止任务；全部完成仍返回刷新计划页。
- **风险**：服务端可能已经接受上次保存/提交，但前端没有跳转；重新点击会有重复创建、投放费用风险。继续前需人工核对平台是否已成功保存。
- 原有 `content.js`、`style.css` 和 `workflow/` 全部保持原样。真实 vivo 页面需进一步验证。
