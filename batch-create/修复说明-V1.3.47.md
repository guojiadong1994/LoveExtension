# LoveExtension V1.3.47 · 一键素材+文案通用预览图

## 功能规则

- 「一键素材+文案」弹窗原「横版预览图」改名「预览图」，支持所有存在独立「预览图/封面」上传区的广告创意类型，而非仅限「激励互动＋竖版视频」。
- 只选择预览图且不选择主素材与标题时，依据当前**已有创意序号**依次替换预览图；每张图仅对应一条创意。
- 普通视频选择主视频 + 预览图时：按索引优先上传所选封面，未选封面的其余视频沿用第三帧抽取/平台生成兜底；不重复执行一轮预览图替换。
- 激励互动＋竖版视频：仍跳过第三帧抽取；选中的预览图通过独立预览图上传引擎替换，允许只覆盖部分视频。
- 图片类创意选择主素材 + 预览图时：先完成主素材处理，再尝试更新其独立预览图上传区；平台未提供该字段则明确报错并停止，不触碰头像或其他字段。
- 选中的预览图不得多于同批主素材或已有创意的数量，发现数量错误时不会开始上传。
- 保留浏览器 File System Access 文件句柄的临时保存机制、原有中断处理、通知与校验。

## 测试范围

- 预览图单独替换：普通视频和图片创意。
- 普通视频预览图优先、不选择仍抽帧、不重复替换。
- 激励竖版视频不抽帧且允许部分手动预览图。
- 图片创意包含主图、独立预览图的组合路径。
- 预览图数量超过主素材/已有创意数量时停止。
- 原批量新建广告流程保持不变。

实际 vivo 后台的特殊创意类型是否存在独立上传区仍以页面 DOM 为准，未在用户真实账号投放验证。
