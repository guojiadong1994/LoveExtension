# LoveExtension V1.3.48 · 批量预览图直接选图

## 边界：两个入口各自独立

- **广告新建/编辑页右键「一键素材+文案」**：保留 V1.3.47 通用预览图与独立替换逻辑，原代码未更改。
- **广告计划列表右键「批量新建广告」**：仅此入口调整任务卡片预览图选择方式。

## 批量入口新规则

1. 「预览图（可选）」像主素材按钮一样直接弹出系统图片选择器；支持同时选多张 JPG/PNG，只显示已选数量，删除原「逐视频设置」窗口。
2. 当前任务需要有「激励互动」广告计划且创意类型为「竖版视频」，并已选择主视频，才能选择预览图。
3. 最多 10 张且不超过所选视频数量，依次映射到创意序号；再次点击可重新选择。
4. 这些图片只在「激励互动＋竖版视频」广告 AD 阶段上传；同任务其他展现形式的广告不使用这批预览图。
5. 普通视频不选此框也不会被特殊处理：保持原自动抽帧逻辑；激励竖版视频没选图的部分直接跳过。
6. 原断点续跑、批量素材句柄、公共参数与自动提交均不变。

## 验证

UI 模拟验证了：非特殊格式禁用预览图按钮、激励竖版视频直接多选图片、不打开逐视频编辑窗口、图片数量显示与任务存储。原广告页一键功能保留 V1.3.47 完整源码。
