# V1.3.28 偶发「行业/产品字段中找不到无遮挡的可点击区域」修复

## 原因及处理
- V1.3.27 在选完「应用」后，立即对「行业/产品」字段进行单次命中检测。如果此时前一个菜单还没完全关闭、界面异步更新或元素仍被遮挡，就会立刻报错，无法自动恢复。
- 新版先等待字段进入可点击状态，最多约 8.5 秒；必要时可检查明确存在的旧下拉浮层并使用 Escape 关闭，再等待。不会点击被未知遮挡物覆盖的控件，也不会替用户保存/提交。
- 改成在目标控件中取多个实际可见坐标；每次点击前重新读取位置，降低渲染后坐标失效的风险。
- 失败错误会显示目标字段尺寸、实际挡住它的元素、探测点数量和加载状态，以便精准排查。
- 左右两级行业/产品仍然按准确文字点击且需要选中回显确认，不放宽安全验证。

该改动仅在 `batch-create/debugger-cascader.js`，另外更新版本号和说明文件，原有悬浮球、媒体上传、右键改名和批量创建其他步骤代码不变。真实 vivo 页面仍需测试。
