# V1.3.31 切换展现形式提示自动确认

- 针对 vivo 「切换展现形式会还原下面所有创意内容，确定切换吗？」的特定系统弹窗，在自动选择新的展现形式时点击一次「确定」。
- 仅识别该准确文案和唯一可用的确认按钮；其他系统弹窗不自动确认。
- 自动确认前要求页面「创意个数 0/10」（数量必须为零）；存在素材或无法识别数量时停止，防止清空已有创意。
- 确认后先等待弹窗消失，再核验目标展现形式选中，才继续。
- 已是目标展现形式则不重复点击。
- 不改旧版悬浮球、右键改名和上传引擎；不改变手动/自动提交广告的审批行为。

本地仅可验证模拟 DOM，需登录 vivo 真实广告页面后验证。
